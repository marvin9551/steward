# 路线图

[English](../roadmap.md) | 简体中文

每个阶段结束时都要有能用的东西。目标是让主循环一直能跑，同时每次只增加一个概念。

## P0 —— 主循环（已完成）

- OpenAI 兼容的流式对话、tool_calls 拼装
- 工具：`read_file`、`write_file`、`edit_file`、`list_dir`、`run_shell`
- 权限模式 + 审批提示
- SQLite 会话，`history` / `sessions` 命令
- 按完整 turn 裁剪上下文、工具输出压缩

**完成标准：** 全新 clone 能改一个文件并解释改动，重启 CLI 能继续之前的会话。

## P1 —— 让它值得信任

- [ ] **摘要被丢弃的 turn。** 当预算迫使旧 turn 离开时，调用一次模型生成简短摘要，作为 system 消息保留。衡量标准：30 轮对话在压缩后仍保持连贯。
- [ ] **取消。** Ctrl+C 应取消进行中的流和工具，在历史里留下 `cancelled` 标记，并保持会话可用。
- [ ] **重试。** 对 429/5xx 做带抖动的退避重试，但**绝不重试**已经落库结果的工具调用。
- [ ] **用量与成本。** 每轮持久化 `usage`；`steward usage` 按天打印 token/成本。在提高步数预算之前必须先有它。
- [ ] **20 条 golden 任务集。** 脚本化 prompt + 期望工具调用，用便宜模型在 CI 里每夜跑。

**完成标准：** 中途杀掉一轮后数据库仍然一致；故意改坏一个工具描述，golden 集能报出来。

## P2 —— 个人助理

- [ ] **记忆文件。** 工作目录里的 `USER.md`（偏好）和 `MEMORY.md`（事实），带长度上限注入系统提示词。第一版优先用可读文件，而不是 embedding。
- [ ] **每日摘要任务。** 每天一次（或每 N 轮），把长期有用的事实追加进 `MEMORY.md`；给模型的提示词保持精简。
- [ ] **定时任务。** SQLite 里存 cron 表，一个 asyncio 任务扫描，结果投递到当前渠道。不重叠：仍在运行的任务跳过，而不是排队。
- [ ] **Telegram 渠道。** 长轮询、按 user id 白名单，复用同一个 `Runner`。这里正是 `on_event` 发挥价值的地方。

**完成标准：** 助理能跨会话记住一个偏好且不依赖向量库；定时任务能扛住重启。

## P3 —— 看见工作过程（已完成）

- [x] **SSE 端点。** `GET /api/stream` 按序号回放事件，断线后能接着看，而不是整段重来。
- [x] **单页 UI。** 对话、工具调用、审批按钮。React 18 + shadcn/ui，后端是一个 FastAPI 应用，没有第二个后端。
- [x] **审批卡片。** 允许一次 / 本次运行始终允许 / 拒绝，由终端提示用的同一张 `policy.decide` 表决定。

**完成标准：** 浏览器和 `steward history` 对同一轮的说法一致——同样的消息、同样的工具调用、同样的结果。

本阶段还留着：文件 diff 视图，以及从页面取消一轮（需要先完成 P1 的取消能力）。

## P4 —— 需要时的边界

- [ ] **沙箱后端。** Linux 用 bubblewrap，macOS 用 Seatbelt，Windows 用 Job Object。启动横幅必须说明命令是否在沙箱内。
- [ ] **MCP 客户端。** 官方 SDK，stdio + HTTP，按 server 配置环境变量白名单。
- [ ] **子 Agent 作为工具。** 启动一个有独立步数/token 预算的受限任务，只返回摘要。不是第二个编排器。
- [ ] **打包。** 带 entry point 的 wheel，以及把工作目录读写挂载、数据目录只读挂载的 Dockerfile。

**完成标准：** "运行这段不可信脚本"在构造上就是安全的，而不是靠约定。

## 明确的非目标

- 多租户鉴权、计费、配额
- 插件市场
- 20 个聊天渠道
- 自研向量数据库
- Agent 编排 DSL

如果将来某个需求确实需要其中一项，它应当附带一份说明"什么变了"的设计决策记录。
